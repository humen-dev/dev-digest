# mcp — specs

Behavior **specifications / contracts** for `@devdigest/mcp`: what each MCP tool
must accept, return and refuse, independent of implementation. Linked (not
preloaded) from [`../AGENTS.md`](../AGENTS.md); read a spec when a task touches it.

Good fits: tool input/output contracts, error mapping from the API, progress
notifications, handling of untrusted finding/convention text.

New specs follow [`../../specs/_TEMPLATE.md`](../../specs/_TEMPLATE.md)
(`YYYY-MM-DD-<feature-slug>.md`, global `SPEC-NN`); features spanning several
modules go to the root [`../../specs/`](../../specs/README.md) instead.
